## Structure

- `gcd/` - Euclid's algorithm, Consecutive Integer Checking algorithm, Middle-school procedure
- `sieve/` - Sieve of Eratosthenes (used by the middle-school procedure)
- `stack/` - list used as a stack, and the MyStack class
- `queue/` - list used as a queue, and the MyQueue class
- `tree/` - Binary Tree with insertion
- `stl_alternatives.cpp` - std::stack, std::queue, std::deque examples

Each file has a `main()` and can be compiled on its own, e.g.:

```
g++ -o euclid gcd/euclid.cpp
./euclid
```
